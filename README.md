# SWYNEX-Business-Intelligence-Case-Study

Hospital Management Analytics Dashboard

Project Overview

This project focuses on analyzing hospital data using Microsoft Power BI to support data-driven decision-making and improve hospital operations.

Business Objectives

- Analyze total patient records.
- Understand the average age of patients.
- Evaluate total hospital billing.
- Compare patients across blood groups, departments, admission types, and hospitals.
- Provide interactive filtering for better analysis.

Tools and Technologies

- Microsoft Power BI
- Power Query
- DAX
- Data Visualization
- GitHub

Dashboard KPIs

- Total Patients
- Average Patient Age
- Total Billing Amount

Dashboard Visualizations

- Patients by Gender
- Patients by Blood Type
- Patients by Department
- Patients by Admission Type
- Patients by Hospital

Business Insights

The final insights will be documented after validating the dashboard data:

1. Patient distribution by gender.
2. Distribution of patients by blood type.
3. Departments with higher patient volumes.
4. Comparison of admission types.
5. Hospital-wise patient distribution.

Deliverables

- Power BI dashboard (.pbix)
- Business Intelligence case study document
- Five data-driven business insights
